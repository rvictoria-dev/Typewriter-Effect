# Typewriter-Effect

### ✨About 

***Typewriter Effect*** is a front-end project that recreates the appearance of text being typed on the screen using only HTML and CSS. The animation reveals characters progressively, creating a classic typewriter-style effect without the use of JavaScript. This project demonstrates the use of CSS animations, timing functions, and creative styling techniques to build engaging user interfaces.

---

### 💡 What I learned

While building this project, I learned several useful CSS concepts and techniques:

- How CSS animations can create engaging visual effects without the need for JavaScript.
- How ``align-items: flex-start`` positions flex items at the start of the cross axis and helps control element alignment within a flex container.
- How ``overflow: hidden`` hides content that extends beyond an element's boundaries, making it useful for effects such as typing animations.
- How ``white-space: nowrap`` keeps text on a single line by preventing it from wrapping.
- How ``border-right`` can be used to create a cursor-like effect, making the typing animation feel more realistic.
- How to use the ``animation`` property to define animation duration, timing, and repetition.
- How the ``step-end`` timing function works and how it can be used to create a blinking cursor effect by updating the animation at the end of each step.

This project gave me a better understanding of CSS animations and showed me how powerful pure HTML and CSS can be for creating interactive user experiences.
